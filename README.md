# Pawsitive Pet Academy

Pawsitive Pet Academy is a static website for an animal care and training school based in Durban, South Africa. The site promotes pet care and training courses for pet owners, aspiring professionals, and anyone looking to build confidence with animals.

## Overview

The website includes:
- A landing page introducing the academy and its learning approach
- An About Us page explaining the academy's mission and values
- A Courses page with available programmes and pricing
- Individual course pages for each certification track
- A fees calculator page
- A contact page with academy information

## Project structure

- `index.html` — home page
- `about.html` — academy background and mission
- `courses.html` — course catalogue and pricing overview
- `details.html` — detailed course information
- `calculate fees.html` — fee estimation page
- `contact.html` — contact information and enquiry details
- `styles.css` — shared styling for the whole website
- `images/` — site graphics and photos

## Technologies used

- HTML5
- CSS
- Static web assets only

## How to run locally

Because this is a static website, you can open any HTML file directly in a browser, or run a local server from the project folder.

### Option 1: Open directly
1. Open the project folder in your file explorer.
2. Double-click `index.html` to open the homepage in a browser.

### Option 2: Run a local web server
From the project root, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Website purpose

The website is designed to help learners:
- browse pet care and training courses
- understand programme pricing and durations
- learn about the academy's values and teaching style
- enquire about booking a course

## Notes

This project is intentionally lightweight and does not use a framework or backend. It is suitable for hosting on GitHub Pages, Netlify, or any static web hosting service.
